# Workshops

> **Looking for a hands-on tour of the full accelerator?** The GenAI IDP Workshop runs on
> **[AWS Workshop Studio](https://catalog.workshops.aws/workshops/c384d63d-3090-44c9-a639-e06dd6d9164f)**
> and is best taken at an AWS-hosted event, such as an enablement session or hands-on workshop for your team, where
> each participant gets a temporary AWS account with the accelerator already deployed.
> AWS customers can request a session through their AWS account team or Solutions
> Architect. You can also work through it self-paced in your own AWS account.

This folder holds the **Amazon Quick Integration Workshop**, a self-guided deep dive
into one integration, which you run in your own AWS account. The two workshops
complement each other:

| Workshop | Delivery | What it covers |
|---|---|---|
| [GenAI IDP Workshop](https://catalog.workshops.aws/workshops/c384d63d-3090-44c9-a639-e06dd6d9164f) | AWS Workshop Studio: instructor-led with provided accounts (recommended), or self-paced in your own account | The accelerator end to end: BDA and Pipeline modes, configuration, assessment, evaluation, HITL review, Knowledge Base, Agent Companion Chat, Test Studio |
| [Amazon Quick Integration Workshop](./amazon-quick-integration-workshop.md) | Self-guided, your own account | Driving the accelerator from an Amazon Quick workflow over MCP |

See [Hands-on Workshops](../docs/workshops.md) for which one to choose and how to attend.
