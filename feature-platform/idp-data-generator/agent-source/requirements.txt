# Extra AgentCore-image deps installed on top of the seed-data (SEED generator)
# package. The Dockerfile installs seed-data first (which brings strands,
# weasyprint, augraphy, opencv, reportlab, etc. via its own deps), then these:
#   - idp_common[synthesis]: the accelerator's synthesis adapter glue
#     (idp_common.synthesis.engine drives seed_data.Generator; plus bootstrap,

#   - bedrock-agentcore + uvicorn: the AgentCore HTTP service contract.
#   - aws-requests-auth and requests are pinned here but imported nowhere under
#     agent-source/; job status is written straight to BootstrapTrackingTable
#     with boto3 (runtime/handler.py::_post_status), not posted over HTTP.
#     Whether anything in the image still needs them is unverified — check
#     before dropping the pins.
# idp_common_pkg is provided in the build context by package_agent_source.sh.
