# Benchmark Datasets

The datasets behind the "What we measured" sections, and which problem sets each one
measures. A dataset is not a problem set: one dataset can measure several problem sets, and
a problem set can need several datasets.

| Dataset | Kind | Splitting and classification | Extraction | Confidence | Deployed to Test Studio |
|---|---|---|---|---|---|
| [Synthetic bank statements](#synthetic-bank-statements) | Synthetic, exact ground truth | Boundaries only | **Yes**: long lists | **Yes**: field scores | No (generated by the benchmark) |
| [RealKIE-FCC-Verified](#realkie-fcc-verified) | Public, real documents | No (one class) | **Yes** | Weakly | Yes |
| [DocSplit-Poly-Seq](#docsplit-poly-seq) | Public, real pages | **Yes** | No | **Yes**: class scores | Yes |
| [OmniAI-OCR-Benchmark](#omniai-ocr-benchmark) | Public, real images | No (see below) | Yes: single-page images | No | Yes |
| [Fake-W2-Tax-Forms](#fake-w2-tax-forms) | Public, synthetic forms | No | Not yet measured | No | Yes |

None of these covers handwriting, identity documents, long narrative text or rule
validation.

## Synthetic bank statements

- **Source:** generated by the benchmark suite
  (`benchmarks/corpus/generators/bank_statement.py`). Deterministic, so the same documents
  come back every time.
- **Size:** statements from 5 rows on 1 page to 3,200 rows on 66 pages, plus variants with
  wide tables, several separate lists, long descriptions, and files that contain two
  statements.
- **Ground truth:** exact. Every transaction row carries a unique tag, so the scorer knows
  which rows came back and compares each row's date and amount exactly.
- **Measures:** extraction completeness and accuracy across document sizes, field-confidence
  calibration and discrimination, and split boundaries on one- and two-statement files.
- **Limits:** clean, regular tables with no scan noise, and a single document type. Errors
  are rare, which is good for completeness and poor for measuring confidence.

## RealKIE-FCC-Verified

- **Source:**
  [amazon-agi/RealKIE-FCC-Verified](https://huggingface.co/datasets/amazon-agi/RealKIE-FCC-Verified),
  invoices for broadcast advertising, taken from US Federal Communications Commission
  filings.
- **Size:** 75 invoices in the test set. The benchmark uses the first 20 (81 pages).
- **Ground truth:** human-verified values for header fields (agency, advertiser, totals,
  payment terms, commission) and a list of line items. Scored by Stickler as weighted
  accuracy.
- **Measures:** extraction on real documents with real layout variation.
- **Limits:** one document type; 20 documents is a small sample, so differences under about
  5 points are within two standard errors.

## DocSplit-Poly-Seq

- **Source:** [amazon/doc_split](https://huggingface.co/datasets/amazon/doc_split), packets
  built from pages of [RVL-CDIP-N-MP](https://huggingface.co/datasets/jordyvl/rvl_cdip_n_mp).
- **Size:** 500 packets, 13 document types, 5–20 pages each, built by joining whole documents
  of different types in sequence. The benchmark uses the first 20 packets (298 pages).
- **Ground truth:** the class of every page and the page range of every section.
- **Measures:** page classification, section boundaries, and classification confidence.
- **Limits:** no extraction ground truth, so it cannot show how split errors affect
  extracted values. Neighboring documents are always of different types.

## OmniAI-OCR-Benchmark

- **Source:** [getomni-ai/ocr-benchmark](https://huggingface.co/datasets/getomni-ai/ocr-benchmark).
- **Size:** 293 single-page images across 9 document formats in the test set.
- **Ground truth:** structured values for each image.
- **Measures, as used here:** the benchmark takes the first 20 images, which are all bank
  checks, so in our results it measures extraction from one kind of single-page image, and
  it does **not** measure classification. A stratified sample would be needed to use its
  nine formats.

## Fake-W2-Tax-Forms

- **Source:**
  [singhsays/fake-w2-us-tax-form-dataset](https://huggingface.co/datasets/singhsays/fake-w2-us-tax-form-dataset),
  synthetic US W-2 forms with fake personal data.
- **Size:** 2,000 form images with 45 ground-truth fields each.
- **Status:** deployed to Test Studio with every stack, but not yet part of the benchmark
  suite. It is the closest available dataset for fixed-field forms, so you can run it on
  your own stack today.

## Running these yourself

Every public dataset above except the synthetic statements is loaded into Test Studio when a
stack is deployed, each with a matching configuration profile. See
[Pre-Deployed Test Sets](../test-studio.md#pre-deployed-test-sets). The benchmark suite,
which runs the full matrices and scores them, is described in
[Benchmarking](../benchmarking/index.md).
